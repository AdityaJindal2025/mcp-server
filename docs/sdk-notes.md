# MCP TypeScript SDK v2: spike findings (T0.3)

Pinned: `@modelcontextprotocol/server@2.3.1`, `@modelcontextprotocol/node@2.1.1`, `@modelcontextprotocol/client@2.3.1` (dev), `zod@4.6.7`. Verified 2026-10-17.

| #   | Question                                                    | Finding                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --- | ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Register a tool with zod input/output schemas + annotations | `server.registerTool(name, { title, description, inputSchema: z.object(...), outputSchema: z.object(...), annotations }, async (args, ctx) => CallToolResult)`. Import zod as `zod/v4` or `zod` (v4).                                                                                                                                                                                                                                                                                                                                   |
| 2   | Emitted JSON Schema                                         | Converted by zod v4 `toJSONSchema`. Emits `$schema` (draft 2020-12), `minItems` for `.min(1)`, `minimum`/`maximum` = ±2^53-1 for `.int()`, and `additionalProperties: false` for `.strict()`. No `format`/`pattern` unless `.email()`, `.url()` or `.regex()` is used, so we avoid those (D7). `$schema` is not on the C4 ban list, so the linter allows it.                                                                                                                                                                            |
| 3   | `structuredContent` + text                                  | Return both. The SDK validates `structuredContent` against `outputSchema`. A mismatch, such as an unknown key under `.strict()`, becomes an `isError` result ("Output validation error: …"), not a protocol error.                                                                                                                                                                                                                                                                                                                      |
| 4   | `isError` results                                           | Return `{ isError: true, content: [...] }`. No `structuredContent` is required on errors, and the SDK does not validate output for them.                                                                                                                                                                                                                                                                                                                                                                                                |
| 5   | Serving `2026-07-28` and `2025-11-25`                       | The default `SUPPORTED_PROTOCOL_VERSIONS` (legacy `initialize`) tops out at `2025-11-25`. The modern era (`2026-07-28`) is negotiated via `server/discover` and is enabled by serving through the factory-based entries: **`serveStdio(factory)`** (from `@modelcontextprotocol/server/stdio`) and **`createMcpHandler(factory)`** for HTTP. Both serve legacy traffic from the same factory by default (`legacy: 'serve'` / `'stateless'`). Plain `server.connect(new StdioServerTransport())` would be 2025-only, so we don't use it. |
| 6   | Stateless Streamable HTTP                                   | `createMcpHandler(factory, { legacy: 'stateless' })` gives a web-standard `{ fetch, close }` handler. Wrap it for `node:http` with `toNodeHandler(handler)` from `@modelcontextprotocol/node`. The legacy leg answers `GET`/`DELETE` with 405. The entry does no Host/Origin/auth validation, so we put our own middleware in front. `req.auth` is forwarded as `authInfo`.                                                                                                                                                             |
| 7   | In-memory transport for tests                               | `InMemoryTransport.createLinkedPair()` passed to `serveStdio(factory, { transport })`. Client: `new Client(info, { versionNegotiation: { mode: 'legacy' } })` negotiates `2025-11-25`; `{ mode: { pin: '2026-07-28' } }` negotiates the modern era. `client.getNegotiatedProtocolVersion()` reports it.                                                                                                                                                                                                                                 |

Consequences for the code:

- `createServer()` in [src/server.ts](../src/server.ts) is a **factory** (`McpServerFactory`), called once per stdio connection or once per HTTP request. All shared state (Google client, rate limiter, idempotency cache, audit sink) lives in a `deps` object created once, outside the factory.
- Input validation errors from zod are already turned into `isError` results by the SDK (C7). Semantic checks with custom messages (allowlists, CR/LF, limits) live in `src/lib/guards.ts`.
